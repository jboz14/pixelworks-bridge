Make it look nicer

Polish adds a soft gradient, an inner border, a shadow and rounder corners to the selected frame and everything inside it. Only plain colors are changed. Ctrl+Z undoes it. Roblox imports gradients, borders and shadows.

Roblox fonts

➕ Add my own font
Use a Roblox font name (like Oswald) or a Roblox font asset id. Pick a Google font so Figma can show something close. It is saved and stays in the Mine group.
Figma cannot use Roblox fonts, so it shows the closest Google font (if your Figma has it). Roblox always uses the real font from the @font tag in the layer name.

Text animations

Select a text layer, then press an animation. Press again to remove it. Wave, shake, pop, rainbow and glitch need one-line text; gradient and glow work on any text. Mix a font with an animation, e.g. Title @font(font=LuckiestGuy) @textwave @textglow.

Quick looks (no key needed)

Select a frame, then click a look. It is drawn here and rebuilt in Roblox from the tag. Change its colors, size and opacity later in ✨ Effects ▸ Settings.

Roblox Creator Store textures

Select a frame, search, then click a texture to use it as the background. Needs your Roblox Open Cloud key with the “Creator Store Products: Read” permission.
🎮Game-style looks: glossy buttons, trimmed panels, stat bars and pixel / retro UI (wood, stone, parchment, rarity slots). Select a frame and tap a look, or tap with nothing selected to make a new one.
